# NotLettersHUB

NotLettersHUB — desktop-приложение для Windows для работы с несколькими почтовыми аккаунтами через [NotLetters](https://notletters.com).

Приложение помогает импортировать аккаунты, получать письма через NotLetters API, быстро искать сообщения и обновлять почты вручную или пачками.

## Возможности

- Несколько почтовых аккаунтов в одном интерфейсе.
- Добавление, редактирование, удаление и TXT-импорт аккаунтов.
- Глобальный API-ключ NotLetters и токены на уровне аккаунтов.
- Просмотр писем выбранного аккаунта.
- Поиск по письмам.
- Ручное обновление выбранной почты.
- Массовое обновление всех почт пачками через `Обновить всё`.
- Локальное хранение настроек в профиле пользователя Windows.
- Тёмный компактный UI на Flet.

## Данные

Пользовательские данные хранятся локально:

```text
%LOCALAPPDATA%\NotLettersHUB
```

В папке установки и внутри exe не хранятся аккаунты или API-ключи.

## Запуск из исходников

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Сборка

```powershell
.\build_exe.ps1
```

Готовая portable-сборка появится в:

```text
dist\NotLettersDesktop
```

## Релизные файлы

- `NotLettersHUB_x64_Setup.exe` — установщик для Windows.
- `NotLettersHUB_x64_portable` — portable-версия без установки.
- `NotLettersHUB_v2.0.0_sources.zip` — исходный код релиза.
